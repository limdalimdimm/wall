# limdim.softie

Website showroom cho túi vải hoa & cói handmade.

## Cấu trúc
- `index.html`: khung trang
- `style.css`: giao diện
- `script.js`: dữ liệu sản phẩm, đa ngôn ngữ VI/EN, hiệu ứng
- `images/`: toàn bộ ảnh

## Chạy thử
Mở `index.html` bằng trình duyệt (cần mạng để tải Google Fonts).

## Đăng lên GitHub Pages
1. Tạo repo mới, upload toàn bộ file và thư mục `images/`.
2. Vào Settings → Pages → Branch `main` / root → Save.
3. Sau ít phút trang chạy tại `https://<tên-github>.github.io/<tên-repo>/`.
