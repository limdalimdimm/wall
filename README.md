# limdim.softie

Website bán túi vải hoa & túi cói handmade (song ngữ VI/EN).

## Cấu trúc
- `index.html` – trang chính
- `style.css` – giao diện
- `script.js` – menu, giỏ hàng, booklet, feedback
- `images/` – toàn bộ ảnh

## Đưa lên GitHub Pages
1. Tạo repo mới, upload toàn bộ file/thư mục này (giữ nguyên thư mục `images`).
2. Settings → Pages → Source: *Deploy from a branch* → chọn `main` và thư mục `/ (root)`.
3. Chờ ít phút, website sẽ có tại `https://<username>.github.io/<tên-repo>/`.
